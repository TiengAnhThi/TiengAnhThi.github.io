# Cấp xã/phường lớp 3 — ngân hàng giới hạn độ khó

Đã thay toàn bộ 2.000 câu trong JSON và dữ liệu nhúng. Các mẫu câu chỉ dùng cấu trúc ngắn, từ vựng gần gũi và dạng bài nhìn thấy trong 26 ảnh tham khảo: từ vựng đồ vật, vị trí, hoạt động, số nhiều, hỏi tên/tuổi, điền chữ, nghe, ghép câu, hình ảnh. Không dùng ngữ pháp lớp cao, đoạn văn dài, so sánh hơn, thì hoàn thành hay câu điều kiện.

Đây là 2.000 câu tự tạo theo phạm vi ảnh mẫu, không phải 2.000 câu trích nguyên từ 26 ảnh. Chưa có đánh giá sư phạm từng câu; không thể bảo đảm tuyệt đối tương đương độ khó nếu chưa có giáo viên duyệt.
